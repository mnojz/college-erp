# Project Guidelines & Rules

## UI & Component Design

### Badges & Pill Elements
- **No Solid or Visible Borders**: Never add solid borders, colored borders, or outline borders to badge-like UI elements (e.g. `border`, `border-primary/20`, `border-amber-500/30`, `border-emerald-500/30`).
- **Solid Text with Semi-Transparent Background**: All badge-like UI elements must use solid-colored text or icons and a matching semi-transparent background of the same color (e.g. `bg-primary/15 text-primary`, `bg-emerald-500/15 text-emerald-700 dark:text-emerald-400`, `bg-amber-500/15 text-amber-700 dark:text-amber-400`, `bg-destructive/15 text-destructive`).
